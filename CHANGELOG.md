# Changelog

## Unreleased — 0.4.0-alpha01

- Target Android TV / Google TV with Xiaomi as the first verified prototype device.
- Ask users to select their own Live TV HDMI input; use provider-neutral wording.
- Remove the personal dock migration so updates do not replace saved favorites or column count.
- Use a separate `.debug` application ID for development builds.
- Configure optional release signing from environment variables; builds without credentials produce an unsigned release APK rather than using a debug key.
- Add public installation, compatibility, privacy, contribution, release, and issue-reporting documentation, plus GitHub build checks.

## Personal prototype — 0.3.0

Native CleanYourTV derivative with a three-slot favorites dock, on-TV favorite ordering and hidden apps, persistent focus, a saved HDMI shortcut, and optional Home-button routing. Tested on Xiaomi MiTV-MOOR0, Android TV 11. Not a published public release.
